# Viking Carcassonne 🛡️

Welcome to **Viking Carcassonne**, a custom Java-based adaptation of the iconic board game, re-imagined with a Viking aesthetic.

### 🎓 Context & Purpose
Developed during my **Arts & Multimedia** and **Media Informatics** studies at **LMU Munich**, this project was created for the *Softwareentwicklungs-Praktikum (SEP)* course. Over the semester, our team of 5 developed a complete application from the ground up to gain practical experience in Java development and software engineering workflows.

### 🎨 Features & Design
* **Classic Mechanics, New Theme:** Traditional Carcassonne rules adapted into a custom Viking setting.
* **Custom Frontend:** Custom-designed visual assets and UI matching the Norse theme.
* **Java Architecture:** Built to demonstrate clean object-oriented design and core Java concepts.
